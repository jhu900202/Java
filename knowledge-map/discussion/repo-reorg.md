# 저장소 정리 논의

## 배경
이 리포는 "학습 기록(당시 상태 보존)"이라는 가치와 "공개 리포로서의 위생(민감값·바이너리·빌드 불가 설정·인코딩 혼재)"이 충돌합니다. 어느 쪽을 우선할지에 따라 정리 범위가 달라집니다. 참고할 이력: 2019-02-15 "문서 정리" 커밋에서 flat 구조(`src/study/*_181218.java`)를 날짜 패키지로 한 번 재편했고, 2019-04-24 "정리" 커밋에서 `naver.html`을 지웠다가 바로 되돌렸습니다. 즉 지금 구조 자체가 당시의 정리 결과이며, 삭제에는 신중했던 흔적이 있습니다.

## 전제
- 결정이 아래 "결정 기록"에 적히기 전에는 `src/`, `SMSlib/`, IDE 설정을 수정·이동·삭제·재인코딩하지 않습니다. 지식맵 문서만 만듭니다.
- 어떤 방향을 택하든 **Coolsms API 키 폐기**(서비스 콘솔에서)와 **원본 고정 태그**(예: `archive/2019-academy-end` → 커밋 7372e60)는 코드 변경 없이 먼저 할 수 있는 안전장치입니다.

## 큰 방향 (하나를 고릅니다)

| 방향 | 내용 | 노력 | 장점 | 단점 | 어울리는 경우 |
|---|---|---|---|---|---|
| **A. 동결 + 지식맵 오버레이** | 소스·구조·이력을 그대로 두고 문서(CLAUDE.md, 지식맵, README)만 추가. GitHub Archived 전환은 선택 | 낮음 | 원본 100% 보존. 되돌릴 것 없음. 지식맵이 주제별 뷰를 대신 제공 | MS949 주석은 현재 환경에서 깨져 보임. 민감값·jar·IDE 설정이 그대로 남음 | 기록/기념용으로만 보고 다시 빌드할 계획이 없을 때. **현재 지시("소스는 신경 쓰지 말 것")와 가장 일치** |
| **B. 최소 위생 정리(가역적)** | A 위에, 로직은 안 건드리는 범위에서 항목별 별도 커밋: .gitignore 보강, IDE 설정 정리, jar·덤프 추적 해제, 민감값 플레이스홀더 치환, MS949→UTF-8 변환 | 중간 (반나절, 커밋 4~6개) | 항목 단위로 revert 가능. 한글 주석이 읽히게 되어 지식맵 가치 상승. 시크릿 노출 해소 | 인코딩 변환은 85개 파일 diff가 커서 blame이 몰림(`.git-blame-ignore-revs`로 완화). Var1.java는 복구 불가 | 공개 포트폴리오로 두면서 "열어서 읽을 수 있는" 상태를 원할 때 |
| **C. 제자리 현대화(Gradle + UTF-8)** | B에 더해 Gradle Wrapper·JDK 17/21 툴체인을 추가하고 `src/`를 sourceSet으로 매핑. jar는 Maven Central 의존성으로 대체(Coolsms SDK는 Central에 없음) | 중간 | `./gradlew compileJava`로 오늘 바로 컴파일 검증 가능(스크래치 사본 시험 결과: UTF-8 변환 후 JDK 21에서 135개 중 134개 컴파일, 실패는 Collabo2의 JUnit import 1건). 패키지 구조·이력 유지 | 학습 기록 성격과 다소 충돌. JDBC 예제는 Oracle XE 없이는 실행 불가. Coolsms 예제는 빌드에서 빼거나 로컬 jar로 남겨야 함 | 예제를 실제로 다시 돌려 볼 계획이 있을 때 |
| **D. 주제별 재편(git mv)** | 원본을 태그/브랜치로 동결한 뒤 `src/`를 단원 디렉토리(basics/oop/…)로 재배치. 패키지 선언 수정 필수 | 높음 (1~2일) | 디렉토리만 봐도 주제가 드러남. 지식맵 트리와 1:1 | 135개 파일 package 선언 수정 = 소스 수정. 날짜 시간축이 약해짐. room1/room2처럼 "다른 패키지"라는 사실이 학습 포인트인 예제의 의미가 사라짐. INDEX 36행·단원 evidence 전부 갱신 | 이 리포를 "계속 다듬을 자바 예제집"으로 쓰기로 했을 때만 |

세 관점(보존·현대화·주제별)의 독립 검토가 공통으로 권한 순서: **A를 먼저 확정하고, 논의 후 동의하는 항목만 B로 점진 확장. C/D는 A 위에서 언제든 추가할 수 있으므로 지금 결정할 필요가 없습니다.** 지식맵의 단원 5개는 D의 목표 디렉토리 구조로 그대로 쓸 수 있게 설계했습니다.

## 안건 (현황 / 선택지 / 지식맵 영향)

1. **소스 보존 범위** — 현황: 날짜 패키지 36개, 당시 상태 그대로. 선택지: (a) 완전 동결(권장) (b) 인코딩만 UTF-8 통일 (c) 주제별 디렉토리 재배치. 지식맵 영향: a·b 없음(경로 동일) / c INDEX 36행 + 모든 단원 `evidence` 갱신, 갱신 전까지 전 단원 stale.
2. **하드코딩된 민감값** — 현황: DB 접속 정보(study_190304·190313·190328), SMS API 키·시크릿·전화번호(study_190308_mk3/ExampleSend.java), 사설 IP(study_190318_mk2/SocketClient.java)가 소스와 커밋 이력에 남아 있음. 선택지: (a) 그대로 두고 키 폐기 여부만 확인 (b) 마스킹 커밋(값 → 플레이스홀더, 이력에는 남음) (c) git 이력 재작성(filter-repo) + force push. 지식맵 영향: a·b 없음 / c CLAUDE.md의 커밋 수 등 고정 사실 갱신. **먼저 확인할 것: Coolsms 키가 아직 유효한지.** 참고: DB 쪽은 Oracle 교육용 샘플 계정과 교재 예제 계정이라 실질적 보안 문제는 아니고, 핵심은 SMS API 키·시크릿과 전화번호입니다.
3. **바이너리·덤프** — 현황: `src/study_190304/ojdbc6.jar`(2.1MB, Oracle 라이선스상 재배포 비권장), `SMSlib/*.jar`, `src/study_190311/naver.html`(169KB, 제3자 콘텐츠), `test*.txt`. 팩 크기 약 19.65MiB의 대부분이 jar 이력. 선택지: (a) 유지 (b) `.gitignore` 추가 + 삭제 커밋(이력엔 남음, 용량 회수 없음) (c) `SMSlib/` 또는 `lib/`로 이동 + `.classpath` 갱신 (d) 빌드 도구 의존성으로 대체(방향 C). 지식맵 영향: b·c·d는 단원 05 `evidence`의 SMSlib 항목과 단원 04의 naver.html 주의점 갱신.
4. **IDE 설정 이중 커밋** — 현황: Eclipse(`.classpath`의 Windows 절대 경로, `.project`, `.settings/`)와 IntelliJ(`.idea/`, `Java.iml`, 2021-06-22 추가)가 모두 커밋됨. 두 설정이 서로 다른 출력 경로를 가리킴. 선택지: (a) 유지 (b) IntelliJ만 남김 (c) 둘 다 `git rm --cached` + `.gitignore`. 지식맵 영향: 없음(지식맵은 IDE 설정을 참조하지 않음). CLAUDE.md 고정 사실 한 줄 갱신.
5. **`.gitignore` / `.gitattributes` / `.editorconfig`** — 현황: `.gitignore`는 `/bin/`만, `.gitattributes`는 `* text=auto`. 선택지: `/out/`, `/build/`, `.idea/`, `*.iml`, `.classpath`, `.project`, `.settings/`, `*.class` 추가. `knowledge-map/`만 UTF-8·LF로 못 박는 `.editorconfig` 추가. 지식맵 영향: 없음.
6. **README 추가** — 현황: 없음(LICENSE만). 선택지: (a) 없음 (b) 3~5줄 README에 "학습 기록 리포"임과 `knowledge-map/ROOT.md` 링크, 패키지 명명 규칙(study_/report_ + YYMMDD + Mk/mk/room 변형). 지식맵 영향: 없음. CLAUDE.md는 Claude용, README는 사람용으로 역할이 나뉩니다.
7. **공동 작성 코드와 라이선스** — 현황: report_190227(2인 팀 과제), study_190312/CollaboKHJEdition.java(동료 작성)가 MIT(c) 2019 lpmarz3로 공개됨. 선택지: (a) 그대로 (b) 공동 작성자 표기 확인 (c) 해당 파일 처리 별도 결정. 지식맵 영향: 없음. 지식맵에는 동료 이름·이니셜을 파일명 이상으로 적지 않습니다.
8. **GitHub에서의 표시** — 선택지: 리포 설명·토픽(java, learning) 추가, Archived(읽기 전용) 전환 여부, 공개 유지 여부. 지식맵 영향: Archived로 전환하면 지식맵도 갱신할 수 없으므로 전환 전에 지식맵을 확정해야 합니다.

## 바로 할 수 있는 안전한 항목 (코드 변경 없음)

- 원본 고정 태그 `archive/2019-academy-end`(7372e60, 2019-04-29)와 `v2021-intellij`(b2013c8) 추가. 이력을 바꾸지 않으며 언제든 삭제 가능.
